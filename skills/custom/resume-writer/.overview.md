# resume-writer

## Purpose
Turn a job description plus Clinton's fact base into a tailored, ATS-readable CV and cover letter that read like he wrote them. Facts come only from `references/facts.md`; style from `references/voice.md`; method from the five AI-era rules.

## Key Sections
- Rules that override everything (no invented facts; his voice; map not stuff; scope limits in the letter; Clinton confirms)
- Workflow checklist (JD → jd_match.py → match.md → bullets → honesty pass → build → validate → review)
- Layout, bullets (XYZ), AI proof, cover letter
- references/facts.md — identity, timeline, per-role brain dumps and verified numbers, skills, education, AI proof, numbers he does not have
- references/voice.md — patterns to copy, words to avoid, rewrite examples
- references/ai-era-guidelines.md — the five rules with the data behind them and a pre-send checklist
- references/jd-matching.md — workflow, match.md template, evidence-by-theme table
- scripts/jd_match.py — JD terms mapped / gaps / unused against facts.md
- scripts/build-cv.js — one-column .docx (and .pdf via LibreOffice) from cv.json
- examples/rituals-2026.json — the Rituals Retail Technology IT Architect CV as content
